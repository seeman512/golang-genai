# Домашнє завдання · Урок 2 (Типи даних, Go + GenAI)

Цей репозиторій — готовий каркас для домашнього завдання. Частина завдань
перевіряється **автоматично** через GitHub Actions при кожному пуші чи
Pull Request — просто запуште код у гілку `main` або відкрийте PR і
перевірте вкладку **Actions**.

```
├── cmd/library/main.go   ← CLI: go run ./cmd/library

```

## Завдання 1 — Змоделюйте домен «Бібліотека»

**Перевіряється автоматично тестами `library/library_test.go`.**

1. У файлі `library/library.go` вже задано каркас трьох структур:
   `Author`, `Book`, `Library`. За потреби скоригуйте чи розширте поля —
   головне, щоб залишились щонайменше:
   - `Book.Author` — вкладена структура (`Author` всередині `Book`);
   - `Library.Books` — поле-зріз (`[]Book`).
2. Реалізуйте метод:

   ```go
   func (l *Library) AddBook(b Book)
   ```

   Він має додавати `b` до `l.Books`.
3. Запустіть готовий `main()`, який будує приклад бібліотеки й виводить
   її:

   ```bash
   go run ./cmd/library
   ```

🤖 **Опційна допомога ШІ**: попросіть асистента переглянути дизайн ваших
структур для домену Library і запропонувати одне покращення — а тоді
вирішіть, чи згодні ви.

## Завдання 2 — Сортування книг за роком

**Перевіряється автоматично тестами `library/library_test.go`.**

Реалізуйте функцію в `library/library.go`:

```go
func SortByYear(books []Book)
```

Вимоги:
- сортує `books` за `PublishedYear` (за зростанням) **на місці** (in place);
- **без сторонніх бібліотек** — дозволено `sort.Slice` зі стандартної
  бібліотеки або власний алгоритм сортування;
- коректно працює на вже відсортованому, відсортованому у зворотному
  порядку та порожньому зрізі (усе це перевіряють тести).

Запустити тести локально:

```bash
go test ./library/... -v -cover
```

## Що саме перевіряє CI (GitHub Actions)

Конвеєр `.github/workflows/tests.yml` на кожен push/PR виконує чекліст
із заняття «Значення проти вказівників» та загальний чекліст ідіоматичного
Go:

| Крок                              | Що перевіряє                                                        |
|-----------------------------------|----------------------------------------------------------------------|
| Перевірка структури репозиторію   | Наявні `README.md`, `library/library.go`, `nilslice/nilslice.go`    |
| Перевірка підсумку Завдання 3     | TODO-заглушка в README замінена на власний текст                    |
| `gofmt -l .`                      | Код відформатовано за стандартом Go                                 |
| `go vet ./...`                    | Немає підозрілих конструкцій (типові помилки компілятора)           |
| `go test ./... -v -cover`         | Уся логіка проходить тести з покриттям                              |
| `go build ./...`                  | Проєкт компілюється без помилок                                     |

Якщо будь-який крок впаде — перевірка в Pull Request стане червоною ❌,
і ви побачите точну причину в логах кроку.

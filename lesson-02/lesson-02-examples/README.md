# Приклади коду з лекції · Урок 2: Типи даних у Go

Усі приклади з розширеного конспекту лекції, розкладені по окремих
файлах для демонстрації під час презентації. Кожен файл —
самодостатня програма `package main`, яку можна запустити напряму:

```bash
go run 07-arrays-vs-slices/02-slice-reference-semantics.go
```

Усі 32 файли перевірені: компілюються без помилок і виводять саме
той результат, що описаний у коментарях і в конспекті лекції.

## Порада для демонстрації

Для розділів 06 і 08 (паніки) файли навмисно використовують
`recover()`, щоб панічне повідомлення просто друкувалось у консоль,
а не переривало показ програми аварійно — це дозволяє показати
паніку "живою" і продовжити презентацію без переключення терміналів.

Якщо хочете показати "сиру" паніку без `recover()` (по-справжньому
аварійне завершення програми) — просто заберіть блок
`defer func() { recover() ... }()` з відповідного файлу перед показом.
